# C-001 — A bounded question or outcome

Theme: link to the direction and research context.

## Purpose

Why this matters, what is already known, and what a useful answer enables.

## Requirements

### R1 — Observable outcome or implementation constraint

State what must be established and what evidence would satisfy it. For research,
name the question, comparison and conditions; a credible negative result can
satisfy a question without satisfying a requirement to achieve a performance target.

## Authority and boundaries

Repositories and permitted actions; excluded outcomes; resource/time/spend limits.
Allow experiment design, diagnostic work, changes to task decomposition and
necessary caller/test/documentation updates within those bounds.
Stop the affected work for a changed question, an exceeded budget or an action
outside granted authority. A failed hypothesis alone need not stop investigation.

## Communication

Reader and assumed context. Name any finding that needs a digest before closure.
At closure, explain what the requirements established together. Routine task
updates need only continuation notes.
