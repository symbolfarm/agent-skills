# Goals

One priority-ordered queue across all projects. **Position is priority.**
Project is a tag, not a partition. Queue entries are unnumbered bullets: the
stable `G-NNN` identifier names a goal, while physical order expresses priority.

Claim before working — see `LOCKING.md`. Add a `*Claimed:*` line with agent and
timestamp, commit it, then start.

Only `active` projects with a non-empty `agent_may` may hold goals.

## Queue

- **G-001** `project-id` — One-line outcome.
  *Done when:* something a third party could check without asking what was meant.

## Not queued, deliberately

- Things that need scoping before they can become goals, and why.
