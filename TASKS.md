# Tasks

> Agents: read this file at the start of every session, then consult
> `.tasks/LOG.jsonl` for the current task queue. The `work-cycle` skill describes
> how to start, execute, and complete tasks.

## Current focus

Keep the four public workflow skills aligned with their documented item model.

## Structure

- `.tasks/LOG.jsonl` — current and historical task state
- `.tasks/*.md` — pending or active work orders
- `.tasks/debriefs/` — durable close-out context
